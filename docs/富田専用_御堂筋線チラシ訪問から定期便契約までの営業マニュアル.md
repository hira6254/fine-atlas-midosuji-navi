## 1. まず深く理解しよう：ファインアトラスはどんな会社？

### 1-1. 2つの会社の強みが合わさって誕生（2026年9月設立）
- **株式会社ファインスタッフ**：ホテル・飲食業界の「人材不足・調理人不足」に長年向き合ってきた経験
- **対馬水産株式会社**：水産物の加工・鮮度保持・国内外への販路開拓に挑んできた経験（海外事業部を分離・承継）

### 1-2. お店（料理長・オーナーシェフ）にとっての本当の価値
飲食店の厨房では、毎朝の仕入れと**「ウロコ引き・内臓処理・ヌメリ取り・開き・長時間の炊き番」**に膨大な時間が奪われています。一方で二番手・見習いの採用は年々難しくなっています。

ファインアトラスは：
1. **産地で時間を止める**：旬や大漁の日に産地で買い付け、提携加工場で素早く下処理・真空包装・急速冷凍（高品質確保＆価格変動の抑制）。
2. **現地で時間を動かす**：お届け先地域の拠点で、お店の注文に合わせて必要な分だけ解凍・仕込みを行い、**使いやすいチルド状態（商品により冷凍納品も可）**でお届け。
3. **料理人のこだわりを守る下処理代行**：「既製品で手抜きする」のではなく、**「一番しんどい生開きや三枚おろしだけを任せ、自店のタレや火入れで最後のひと手間を仕上げる」**ことで、料理人が調理と接客に集中できる環境をつくります。

## 2. なぜ「いきなり定期便を売らず、まずチラシご挨拶アポ」なのか？

料理長やオーナーシェフは、見ず知らずの会社から電話で「定期便を契約してください！」と言われても絶対に買いません。
逆に、**「お電話口での営業は一切いたしません。御堂筋線ですぐ近くを回っている新人の富田と申しまして、1分だけ会社案内のチラシを置きにご挨拶へ伺ってもよろしいでしょうか？」**と伝えれば、驚くほど高い確率で「チラシ置いといてくれる分にはええよ」と受け入れてもらえます。

### 黄金の4ステップ育成フロー

| ステップ | 目的（ゴール） | やること・時間目安 |
| :--- | :--- | :--- |
| **STEP 1：電話（60秒）** | 売り込みゼロで「チラシ持参（または投函）許可」を取る | 冒頭で「お電話口での営業は一切いたしません」と言い切る。訪問OKな時間帯と定休日を確認する。 |
| **STEP 2：初回訪問（90秒）** | 約束通り売り込まず爽やかに帰り、顔と名前を覚えてもらう | 清潔感のある挨拶でチラシと名刺を手渡し。余裕があれば「普段どんな魚の下処理が一番手間ですか？」と1問だけ聞いてサッと退店。 |

| **STEP 4：定期便ご契約へ** | お試し後の感想を聞き、5項目ヒアリングで個別見積りへ繋ぐ | 用途・希望魚種/サイズ/量・任せたい下処理・納品形態/曜日を聞き取り、上長（今田代表・尾崎さん・平林さん）と連携して個別ご提案！ |

## 4. 絶対に守る「5つの誠実ルール」（業務事故防止）

1. **価格・最低ロット・配送曜日・送料・サンプル条件を独断で断定しない**：すべて店舗ごとの用途・加工度に応じた**個別確認事項**です。聞かれたら「お試しセットは税込10,000円（Web決済）です。定期便の条件はご希望の魚種や加工度を伺って個別にお出ししております」と誠実に答えましょう。
2. **お試しセットの最新在庫・内容は商品ページで確認する**：甘鯛・剣先イカ・生穴子・のどぐろ・煮穴子などは過去の掲載例です。案内前に公式商品ページ（https://zmqxpe-6h.myshopify.com/products/trialset ）を確認しましょう（配送対象：大阪市全域・豊中市・吹田市・箕面市）。
3. **対馬水産の実績と混同しない**：対馬水産の過去実績をファインアトラス自身の契約実績のように話すのは誤りになります。「対馬水産の事業を承継し、ファインスタッフと共に2026年9月に設立した新会社です」と正確に伝えましょう。
4. **未公表の社内計画数字は外で言わない**：拠点の具体的な開業日や目標店舗数など、公式HPに出ていない社内計画は対外トークで断定しないこと。
5. **営業時間ピーク（11:30〜14:00 ／ 17:30以降）と定休日は避ける**：必ずアイドルタイム（主に14:00〜16:45頃）に連絡・訪問しましょう。
