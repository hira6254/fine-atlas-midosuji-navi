# FINE ATLAS 🚇 御堂筋線（江坂〜梅田）チラシ訪問＆関係構築ナビ（富田専用）

株式会社ファインアトラス（ファインスタッフ × 対馬水産）の新人営業・**富田君専用**の、Osaka Metro 御堂筋線（江坂駅 `M11` 〜 梅田駅 `M16` ＋ 地下徒歩圏の北新地・堂島・西天満）で電車移動しながら回れる**実在精査済み架電＆チラシ訪問リスト・4段階トークスクリプト・実践Webサイト**です。

## コンセプト：いきなり売り込まず「ご挨拶 → 人間関係 → お試し体験 → 定期便契約」へ

1. **STEP 1（電話 60秒）**：お電話口での営業は一切せず、「御堂筋線ですぐ近くなので、1分だけ会社案内のチラシをお渡しにご挨拶へ伺ってもよろしいでしょうか？（忙しければポスト投函でもOK）」の許可だけを取る。
2. **STEP 2（初回訪問 90秒）**：約束通り90秒以内に爽やかにチラシと名刺を手渡し、「普段どんなお魚の下処理が一番お手間ですか？」と一言だけ聞いて顔と名前を覚えてもらう。
3. **STEP 3（2〜3回目再訪）**：人間関係を育てながら、まずは自店の厨房で鮮度・サイズ・歩留まりを確かめられる公式**「お試しセット（税込10,000円・Webクレカ決済）」**をご案内。
4. **STEP 4（定期便ご契約へ）**：お試し後の感想と「5つの個別確認項目（用途・魚種/サイズ/量・任せたい下処理・納品形態/曜日・現状の課題）」をヒアリングし、店舗ごとの個別条件でチルド定期便へ繋ぐ。
